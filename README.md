# IFTIKHARI Marriage Hall - Official Next.js Website

A high-performance, mobile-first wedding and banquet venue website for **IFTIKHARI Marriage Hall, Hazara Town, Quetta**.

## Tech Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS
- Lucide React Icons
- Semantic SEO & LocalBusiness Schema + FAQPage Schema
- AI/GEO Ready (`public/llms.txt`, `public/llms-full.txt`, dynamic `robots.ts`, dynamic `sitemap.ts`)

## How to Run Locally

1. Extract the zip file and navigate into the folder:
```bash
cd my-business-website
```

2. Install all dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
